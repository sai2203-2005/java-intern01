# Console Calculator (Java Practice Project)

A interactive menu-driven console application written in Java that performs basic mathematical operations.

## Features

- **Addition (+)**: Sum of two integer values.
- **Subtraction (-)**: Difference of two integer values.
- **Multiplication (*)**: Product of two integer values.
- **Division (/)**: Quotient calculation returning floating-point result (`double`).
- **Modulus (%)**: Remainder calculation for two integer values.
- **Interactive Loop**: Runs continuously until option 6 (Exit) is selected.

## How to Run

### Prerequisites
- JDK 8 or higher installed on your system.

### Compilation
```bash
javac Practise.java
```

### Execution
```bash
java Practise
```

## Example Usage
```text
1.Addition
2.subtraction
3.multiplication
4.Divison
5.Modulus
6.Exit
Enter Your choice : 1
```
